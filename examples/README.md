# Capability usage examples

These declarations exercise three practical gooo questions:

- reverse-observation.gooo asks how a result can be traced back to evidence.
- code-generation.gooo asks how an implementation boundary can be generated.
- lsp-feedback.gooo asks how feedback can become language guidance.

Each file is a small declaration input for the capability discovery and
overview APIs. A matched catalog capability is an available or deferred
language boundary, not a claim that the whole language is complete. Missing
signals remain explicit so the next declaration or evidence step is visible.
