# Capability review

Review candidates are the final boundary before a catalog change. They are not automatic language mutations.

A candidate is PRESERVED when discovery is UNKNOWN or DEFERRED, PENDING_PROPOSAL when verified feedback exists but a capability id or rationale is missing, and PROPOSED only when both are explicitly supplied. Every state carries feedback, rationale, and candidate digests.

This keeps self-improvement inspectable: evidence can produce a proposal, but proposal creation does not change the language catalog.
